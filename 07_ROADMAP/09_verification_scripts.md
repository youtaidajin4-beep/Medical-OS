# 検証用の台本と確認ポイント

**Version 2026-09-17**

自分で読み上げて、画面に何が出るべきかを1つずつ確かめるための台本。
改善を回す土台なので、**「こう出るはず」を先に書いておいて、違ったら記録する**。

---

## 使う前に知っておくこと

### 1人で読むと、話者分離は必ず失敗する

マイクに入るのが1人の声なので、システムは話者を1人と判定し、**全セグメントを「不明」にする**。
これは設計どおりの動作で、不具合ではない。1人で読むときは、

> 要確認：医師と患者を聞き分けられませんでした（話者がすべて「不明」）

が**出るのが正解**。出なかったらそちらが異常。

**話者分離そのものを検証したいときは、必ず2人で読む。**
1人しかいないときは、片方をスマホの読み上げ（テキスト読み上げ機能）に喋らせて、
**スマホを患者さんの席に置く**。距離も同時に試せるので、これが一番実戦に近い。

### 用量を言うと「要確認」が出て、書類作成がブロックされる

薬剤名・用量・検査値・アレルギー・否定表現・左右は `critical` 扱いで、
**未承認のまま書類を作ろうとすると止まる**（`assertHighRiskKnowledgeApproved`）。

> 要確認の医療用語が N 件残っています。レビュー画面で確定してから書類を作成してください。

これも**出るのが正解**。レビュー画面で確定してから書類へ進む。

### 録音の長さとしきい値

SOAPを空欄にするかどうかは、録音の長さに対する文字数で決まる（12文字/分）。

| 録音 | これ未満なら「録れていない」扱い |
| --- | --- |
| 3分 | 36文字 |
| 5分 | 60文字 |
| 15分 | 180文字 |
| 20分 | 240文字 |

台本①〜③は普通に読めば軽く超える。**台本④はわざと下回らせる**ためのもの。

## 台本① 通常診察・再診（高血圧フォロー）／約3分

**目的**：いちばん多い形。SOAPの型・A/P結合・薬剤補正・話し言葉の略語をまとめて見る。

**準備**：患者ページで患者を1人選ぶ → 「通常診察」→「この患者で診療開始」

> **医師**：こんにちは。お変わりないですか。
>
> **患者**：はい、だいたい変わりないです。ただ、朝の血圧がちょっと高い日があって。
>
> **医師**：おうちで測った血圧はどれくらいでしたか。
>
> **患者**：朝が百五十くらいで、夕方は百四十くらいです。
>
> **医師**：アムロジピンは毎日飲めていますか。
>
> **患者**：はい、朝に一錠、欠かさず飲んでいます。
>
> **医師**：ふらつきやむくみは出ていませんか。
>
> **患者**：ふらつきはないです。足のむくみもないと思います。
>
> **医師**：お薬で困っていることは他にありますか。
>
> **患者**：特にないです。たまに頭が重い感じはありますけど、痛みというほどではないです。
>
> **医師**：分かりました。今日の血圧を測りますね。……百四十七の九十二です。少し高めですね。
>
> **医師**：胸の音を聴きます。息を吸って、吐いて。……心音は整っています。呼吸音も異常ありません。
>
> **医師**：足を見せてください。下腿の浮腫はなしですね。
>
> **医師**：前回のエーワンシーは六点二でした。今回も採血しておきましょう。
>
> **医師**：お薬は今のまま続けます。塩分を控えめに、体重も測っておいてください。
>
> **医師**：二週間後にまた来てください。何かあれば早めに受診してくださいね。
>
> **患者**：分かりました。ありがとうございます。

### こう出るはず

| 見るところ | 期待 |
| --- | --- |
| 文字起こし | 「エーワンシー」が **HbA1c** に補正されている |
| 文字起こし | 「アムロジピン」が薬剤として拾われている |
| 話者 | 2人で読んだ → 医師/患者に分かれる ／ 1人で読んだ → 全部「不明」＋警告 |
| S | 血圧が高い日がある、朝150・夕方140、ふらつきなし、といった**患者が言った事実**だけ |
| O | BP 147/92、心音整、呼吸音異常なし、**下腿浮腫なし**（否定がひっくり返っていないか） |
| A | 高血圧のコントロールがやや不良、といった評価 |
| P | アムロジピン継続、塩分制限、体重管理、2週間後再診、採血 |
| A/P結合 | SOAP欄の下に `A/P：……` の形で出る（カルテ貼付用） |
| 要確認 | 用量まわりで数件出る。書類はこれを確定してから |
| 実行ログ | `transcript=◯◯字 / 必要=◯◯字` が残っている |

### 特に見てほしいこと

- **「ふらつきはない」「むくみもない」が、SOAPで肯定に化けていないか。** 否定の取り違えは一番危ない
- **「頭が重い感じはあるが痛みというほどではない」がどう書かれるか。** 症状として立ててしまうか、落とすか。先生の感覚と合うか
- **散文になっていないか。** 「〜を認めます」「〜と考えます」が出たらプロンプトの意図と違う（事実の短句のみが設計）

## 台本② 健診／約2分

**目的**：健診の型（CXR・ECG）が出るか。

**準備**：患者を選ぶ → **「健診」** を選んで開始

> **医師**：今日は健診ですね。体調で気になるところはありますか。
>
> **患者**：特にないです。元気にしています。
>
> **医師**：お薬は何か飲んでいますか。
>
> **患者**：今は何も飲んでいません。
>
> **医師**：では診察します。脈を診ますね。……脈拍に異常はありません。
>
> **医師**：目と口を見せてください。……貧血なし、黄疸もなしです。
>
> **医師**：胸の音を聴きます。……心音、呼吸音ともに異常ありません。
>
> **医師**：お腹を診ます。……肝臓や脾臓の腫れはありません。
>
> **医師**：足を見ますね。下腿の浮腫もありません。
>
> **医師**：胸のレントゲンは、有意な異常はありませんでした。
>
> **医師**：心電図も、有意な異常はありません。
>
> **医師**：特に問題ないですね。結果はまた郵送します。

### こう出るはず

| 見るところ | 期待 |
| --- | --- |
| S | `健診で受診。` に近い形 |
| O | 脈拍・貧血・黄疸・心音・呼吸音・肝脾腫・下腿浮腫が並び、**`CXR：` と `ECG：` の行がある** |
| A / P | **空でよい**（健診の型はA/Pを持たない） |
| 定型文ボタン | 健診では「**S/O に定型文**」の1つだけが出る |
| A/P結合 | 健診では出ない（通常診察のみ） |

### 特に見てほしいこと

- **「胸のレントゲン」「心電図」が `CXR：` `ECG：` の表記になるか。** 先生が8/10に指定した書式
- 所見が全部そろっているか。1つ抜けると先生は結局打ち直しになる

## 台本③ 同じ患者の2回目 ＋ 紹介状／約3分

**目的**：**患者ごとの蓄積（③）と、経過を書く書類（④）** の検証。
**台本①と同じ患者**で、①のSOAPを確認済みにしたあとに実施する。

> **医師**：前回から二週間ですね。血圧はどうでしたか。
>
> **患者**：朝がまだ百五十を超える日があります。あと、階段で息が切れるようになりました。
>
> **医師**：息切れはいつからですか。
>
> **患者**：一週間くらい前からです。平らなところは大丈夫なんですけど、階段がしんどくて。
>
> **医師**：夜、横になると苦しくなることはありますか。
>
> **患者**：何回か、寝てから息苦しくて起きたことがあります。
>
> **医師**：足のむくみはどうですか。
>
> **患者**：夕方になると靴下の跡が残ります。
>
> **医師**：診察しますね。……血圧は百五十八の九十四です。心音を聴きます。……脈が不整です。
>
> **医師**：足を診ます。……下腿に浮腫がありますね。両側です。
>
> **医師**：心房細動が出ている可能性があります。心不全の初期かもしれません。
>
> **医師**：循環器の先生に一度診てもらいましょう。紹介状を書きます。
>
> **医師**：それまでは、アムロジピンは続けてください。体重を毎日測ってください。
>
> **患者**：分かりました。

### こう出るはず

| 見るところ | 期待 |
| --- | --- |
| 患者ページ | 「これまでの診療」に **2件** 並ぶ。1回目のSOAPが開いて見える |
| 文字起こし | 「心房細動」が拾われている。「両側」が左右として拾われている |
| 書類 → 紹介状 | **前回（台本①）の内容を踏まえた経過**になっている |
| 紹介状の経過 | 「高血圧で通院中、2週間前は147/92でアムロジピン継続」といった**前回の事実**が入る |
| 紹介状 | **台本に無い出来事が書かれていないか**（作文していないか） |

### 特に見てほしいこと

- **これが④の本番です。** 前回を見ずに書いた紹介状と、見て書いた紹介状は別物になるはず
- **経過の捏造がないか。** 「以前から心房細動を指摘されていた」など、どこにも無い話が出たら失敗
- 患者ページで1回目を開いたとき、**A/Pが結合表示**になっているか

## 台本④ わざと失敗させる／約1分

**目的**：**今日いちばん大事な安全弁の確認。** 録れていないときに定型文が出ないこと。

**やり方**：録音を開始したら、**マイクから離れて、ほとんど何も喋らない。**
1分間で、小声で2〜3語だけ（「えーと」「はい」程度）つぶやいて停止する。

### こう出るはず

| 見るところ | 期待 |
| --- | --- |
| SOAP | **4欄とも空** |
| 赤いパネル | 「音声からSOAPを作成できませんでした」「**あえて空欄にしています**」 |
| 要確認 | **CRITICAL** で理由。「◯分の録音に対して文字起こしが◯文字しかなく…」 |
| ボタン | 「定型文を入れる」と「同じ録音でもう一度SOAPを作る」が出ている |
| **絶対に出てはいけないもの** | `S：体調変わりない。` `O：脈拍異常なし。…` `A：stable` |

**最後の行が、9/5に谷口先生の画面で起きていたことです。** ここが再現したら、今日の修正が効いていない。

### 続けて確認

1. 「**A/P に定型文**」を押す → A欄が `stable`、P欄が `定時薬を継続する。` になり、
   **グレー文字＋「定型文」バッジ**が付く
2. A欄を手で書き換える → **バッジとグレーが外れる**（先生が書いたものになった、という表示）
3. 「**同じ録音でもう一度SOAPを作る**」を押す → 処理が走り直す
   （24時間以内なら通る。過ぎていたら「保持期間が過ぎている」と出る）

## 検証の記録テンプレ

台本を1本やるごとにこれを埋める。埋まったものがそのまま改善のネタになる。

```
日時：
台本：①/②/③/④
録音：◯分◯秒 ／ 1人 or 2人 ／ マイク（内蔵 or 外付け・置いた位置）

■ 文字起こし
  聞き取れていた？（そのまま / 一部違う / 使えない）
  違っていた言葉：「言った言葉」→「出た言葉」
  話者：分かれた / 全部不明

■ SOAP
  そのまま使える？（はい / 少し直す / 作り直し）
  直した箇所：S/O/A/P のどこを、どう直したか
  出てほしかったのに出なかったもの：
  出るべきでないのに出たもの：

■ 要確認
  出た件数：
  妥当だった？（妥当 / うるさい / 足りない）

■ 書類（作った場合）
  どの書類：
  そのまま使える？：
  直した箇所：

■ ひとことで言うと
  （例：「Oの所見は完璧だがPが雑」「否定がひっくり返る」など）
```

## 優先順位

時間がないときは、**④ → ① → ③ → ②** の順。

- **④** は安全に関わるので最優先。ここが崩れていたら他を試す意味がない
- **①** は一番使う形
- **③** は今日作った③④の検証。①をやった後でないとできない
- **②** は健診の日にだけ効く
