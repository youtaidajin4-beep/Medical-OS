# Oの定型を、診察の発話で決める（exam-events）

2026-10-10 導入。通常診察（ROUTINE）で、SOAPのOが空欄になる件への対応。

## 背景（本番の実データ、2026-10-10）
SOAPのある66診察のうちOが空欄だったのは22件。内訳は、材料不足10件（9/17〜9/30。10/2以降はほぼ無し）と、
**定型を入れなかった12件（すべて10/2〜10/7）**。後者は、10/1に入れた「会話に聴診などの語が無ければ、定型のOを入れない」
（`soap-floor-gate.ts` の正規表現）が原因。判定語を広げても拾えるのは12件中3件だけで、残りは診察の語が会話に無かった。
正規表現は、逆に患者の「背中が痛い」にも当たる。

## しくみ
1. 会話から、医師が**この診察で行った身体診察**を、4部位（脈・眼瞼/眼球結膜・心音・呼吸音）ごとに、発話の引用つきでLLMに拾わせる
   （`providers/ai/exam-events.ts`）。抽出・SOAP作成と並べて走る。費用は1診察あたり約1円。
2. **引用を機械で検算する。** 診察の動作の引用が患者以外の発話に実在しなければ、その部位は捨てる。「異常なし」の発話は、
   動作の発話より後ろの6行以内にあるものだけ採る。実在しない引用は、未確認に下げる。
3. 部位ごとに3段に分ける。
   | 段 | 条件 | Oへの入れ方 |
   |---|---|---|
   | 異常なし | 動作も「異常なし」の発話も確かめられた | その部位の定型をそのまま入れる |
   | 未確認 | 動作はあるが結果の発話が無い | 入れる。画面の「貼る前に確認」に、根拠の発話つきで出す |
   | 異常あり | 医師が異常を述べた | 定型は入れない（会話から書く） |
4. 部位が1つも拾えず、聴診などの語だけある会話は、4部位を**未確認**として入れる（確認なしでは入れない）。
5. 何も無ければ空欄。画面に空欄の理由と、「定型文」ボタンの案内を出す。
6. 判定に失敗したとき（API障害など）は、従来の語の判定に戻る。診療は止めない。

実行ログ（`ai_executions` の `exam_events`）に、部位ごとの判定と根拠の引用が残る。「なぜ入った／入らなかったか」を後から辿れる。

## 測定（`eval/run-exam-events-eval.ts`、合成の会話）
現行の正規表現と並べた。診察の言い回しを変えた会話と、診察していない会話（患者の訴え・問診・検査の話・前回の話）で測る。
| 組 | 偽の定型 | 偽の診察 | 異常なしに定型が入った | 診察を拾えた |
|---|---|---|---|---|
| 調整に使った組（54件×3回） | 0 | 0 | 100% | 100% |
| 調整後に足した未見の組（18件×3回） | **0** | **0** | 40〜50% | 71〜79% |
| （参考）現行の正規表現 | 診察なしの会話27件中7件に定型 | | 異常なしの会話20件中10件 | |

読み方：**していない診察を載せない（偽の定型0・偽の診察0）はどの組でも保たれた。** 一方、未見の言い回しでは取りこぼしが出る
（「OKです」「結構です」を異常なしと読まない、動作の無い雑音の指摘を拾わない、など）。取りこぼしは「未確認」に回るか、
空欄になるだけで、安全側に倒れる。調整に使った組の数字は甘いので、判断は未見の組で行う。

## 限界
- 無言の診察は拾えない。診察のときに一言「胸の音を聞きますね」と言う運用が必要（10/9の先生との合意、トリガーワード）。
- 診察中の文字起こしが落とした発話は拾えない。
- 合成の会話での測定。実診察の言い回しは、診察まわりの発話を足して測り直す。
- モデルがすでにOを書いているときは、定型は足さない（心音は書かれたが脈・貧血が無い、など）。
- 対象は通常診察のみ。健診はこれまでどおり。
