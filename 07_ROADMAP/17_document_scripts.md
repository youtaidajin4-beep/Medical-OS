# 書類の流れを通しでやる台本（紹介状／診断書／主治医意見書①②）

2026-10-27。**患者はすべて架空。** 画面で新規登録して録音→要約→サブカルテ（チャット）に入力→書類作成。
項目の出どころは `16_document_fields.md`。

## 共通の進め方

1. 患者を新規登録（各台本の「登録」欄のとおり）。
2. 録音開始 → **会話を読む**（2人で。ふだんの速さで）→「診察を終了して要約」。
3. SOAPが出たら、右側の**サブカルテ（チャット）に「サブカルテ入力」を貼る**（先生が書く想定のもの）。
4. 書類タブで指定の書類を作る → 「見るところ」と照らす。
5. 「空欄であるべき欄」に何か入っていたら、**そこが不具合**。値と書類名を教えてください。

## 台本1：初診・胸の締めつけ → 紹介状＋診断書

**登録**：吉田 悦子 72歳 女性／生年月日 1954/4/1／住所 長崎県大村市（任意）／職業 なし

### 会話
**医師**　どうされましたか。
**患者**　三週間くらい前から、階段を上がると胸が締めつけられる感じがして。
**医師**　どれくらい休むと楽になりますか。
**患者**　立ち止まって二、三分で楽になります。夜や座っているときは出ません。
**医師**　左の肩が重くなったり、冷や汗や吐き気はありますか。
**患者**　左の肩が重いときが、たまにあります。冷や汗や吐き気はありません。
**医師**　持病は。
**患者**　高血圧で、四年前から薬を飲んでいます。入院したことはありません。
**医師**　ご家族に心臓の病気の方は。
**患者**　父が六十二歳で心筋梗塞でした。
**医師**　血圧は152の94、脈は78で整です。心電図は大きな変化はありませんね。胸の音も異常ありません。
**医師**　狭心症の疑いなので、ニトログリセリンを舌下で出します。総合病院の循環器で詳しく診てもらいましょう。

### サブカルテ入力
- 紹介状：「宛先は テスト総合病院 循環器内科 山本先生。傷病名は労作性狭心症の疑い。紹介目的は精査・加療。」
- 診断書：「健診日は今日。血圧・脈・心電図は会話のとおり。判定は入れない。」

### 見るところ
| 書類 | 期待 | 空欄であるべき／禁止 |
|---|---|---|
| 紹介状 | 宛先、傷病名、既往（高血圧4年）、家族歴（父・心筋梗塞62歳）、現在の処方（アムロジピン等＋ニトログリセリン舌下） | 【治療経過】は挨拶のみ（固定）。備考は空 |
| 診断書 | 健診日＝今日、血圧152/94、脈78整、心電図異常なし、自覚症状：胸の締めつけ・**左肩の重さはあり** | **判定A〜G・総合判定は空**／身長・体重・血液は空／**「左肩の重さ…なし」は禁止（反転）** |

## 台本2：再診・認知症 → 主治医意見書①②（自立度を**言わない**版）

**登録**：高橋 ミツ 83歳 女性／生年月日 1943/3/3

### 会話
**医師**　最近はいかがですか。
**患者（娘）**　物忘れが進んでいて、薬を毎朝私がセットしています。
**医師**　アルツハイマーと診断したのは三年前でしたね。
**娘**　はい。デイサービスは週に二回行っています。
**医師**　歩くのはどうですか。
**娘**　家の中は壁を伝って、外は杖と付き添いです。夜はポータブルトイレです。
**医師**　徘徊や、夜に起きて騒ぐことはありますか。
**娘**　徘徊はありません。
**医師**　膝は痛みますか。
**娘**　少し。足もむくみます。体重は46キロで変わりません。
**医師**　血圧とむくみは安定しています。アムロジピン2.5、フロセミド20、ドネペジル5を朝に1錠ずつ続けます。

### サブカルテ入力
「主治医意見書を作成。初回。他科受診なし。」（自立度は**言わない**）

### 見るところ
| 項目 | 期待 | 禁止 |
|---|---|---|
| 診断名 | アルツハイマー型認知症／発症：約3年前（または令和5年頃） | **平成30年頃などの誤った年は禁止** |
| 障害高齢者の自立度 | **空** | J1などの推測は禁止 |
| 認知症高齢者の自立度 | **空** | Ⅱaなどの推測は禁止 |
| 周辺症状 | 徘徊は「なし」（徘徊にチェックが入ってはいけない） | 徘徊=あり は禁止 |
| ②歩行 | 屋外：杖、介助あり／関節痛：膝・軽度／体重46 | 身長は空 |
| 被保険者番号・調査回数 | 空（ヒアリング待ち） | |

## 台本3：同じ患者で、自立度を**言う**版（言ったら入るかの確認）

台本2と同じ会話・登録。サブカルテ入力だけ変える：
「主治医意見書を作成。初回。障害高齢者の日常生活自立度はA1、認知症高齢者の日常生活自立度はⅡa。」

**期待**：障害高齢者=A1、認知症高齢者=Ⅱa が入る。それ以外は台本2と同じ。

## 台本4：診断書で判定を**言う**版

台本1と同じ会話。サブカルテ入力：
「診断書。健診日は今日。血圧は要再検でE、総合判定はEにして。」

**期待**：血圧の判定=E、総合判定=E。言っていない他の判定（脈・心電図）は空のまま。

## 結果の返し方

書類名・台本番号・「入っていた値／期待」を貼ってください。
**空欄であるべき欄に値が入っていた**場合と、**ある／なしが反転していた**場合を優先して直します。
